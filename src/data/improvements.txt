Future Improvements & Feature Ideas:

   - Add method like detectStateFromLocation() using navigator.geolocation

2. Search & Filtering
   - Add fuzzy search for states and districts
   - Add methods to filter states/districts by population, area, etc.
   - Add support for searching in local languages

   - Add postal codes for districts
   - Add neighboring states information

4. Localization

5. Validation & Formatting
   - Add postal code validation
